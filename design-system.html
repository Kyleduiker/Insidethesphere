Typography rules
✓ Do Use serif for addresses, prices, stats, section titles, and review quotes

Use italic serif for the second word in section titles: "The evidence"

Keep eyebrow labels at 9px with generous letter-spacing

Use weight 300 for large display type — thin weights read as luxury

Line height 1.05–1.15 for display, 1.6–1.75 for body
✗ Don't Never use bold serif — it looks editorial, not luxury

Never use more than 2 typefaces on any page

Never set eyebrow labels larger than 10px

Never use text-transform: uppercase on serif type

Never center large blocks of body text

Layout Patterns
These are the recurring structural patterns. Use them consistently across every page.
Dark / light alternation — client page
Client pages alternate section backgrounds in this order:
White → Off-white → White → Off-white → Navy (net sheet) → White → Off-white → Navy (shelter) → Navy (footer)

Never two navy sections in a row. Never two off-white sections in a row. The contrast rhythm keeps the page feeling dynamic without being chaotic.
Grid lines — cards and comps
Instead of individual cards with box-shadows, use a grid line approach: set gap:1px;background:var(--border) on the container and background:var(--white) on each child. The border color bleeds through the gap creating clean editorial grid lines. This is what makes comps and stats look like a luxury magazine spread.

Non-Negotiable Rules
These rules apply to every page, every time. No exceptions.
✓ Always Border radius 2px on cards, buttons, tags — never rounded

Cormorant Garamond for any text over 1.2rem

Red eyebrow label above every section title

40px red accent line below every section title

80px vertical padding on client page sections

Gold for recommended prices and net proceeds — nothing else

Generous whitespace — when in doubt, add more space

Property photo as the gate background

"Prepared for [Name]" on the password gate

Client name in presentation type label on cover
✗ Never No rounded corners (border-radius > 4px) on major elements

No drop shadows except subtle hover states

No gradient backgrounds except the gate overlay and hero

No bullet points in client-facing copy

No emoji in client-facing sections (CTA buttons excepted)

No "Inside The Sphere" branding on the client page gate

No centered body text longer than 2 lines

No more than 3 fonts or 5 font weights total

No red for anything other than accent/CTA — not errors, not warnings

No gradient icon squares (replace with simple SVG or text initials)
